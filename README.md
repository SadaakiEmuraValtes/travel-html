# 🗾 JAPAN TRAVEL — 旅行予約シミュレーター

Vue 3 製の日本国内旅行予約デモサイトです。47都道府県の宿泊施設・移動手段をブラウザ上でシミュレーション予約できます。

**デモ:** https://sadaakiemuravaltes.github.io/travel-html/

---

## 機能一覧

| カテゴリ | 機能 | 説明 |
|---------|------|------|
| 検索 | 宿泊検索 | 47都道府県から目的地を選択し宿泊施設を検索・予約 |
| 検索 | 交通+宿泊セット | 出発地・目的地・交通手段・宿泊をまとめて予約 |
| 目的地選択 | Canvasマップ | HTML5 Canvas描画の47都道府県インタラクティブマップ（ホバーツールチップ付き） |
| 目的地選択 | 地域リスト | 地域 → 県 → エリアの階層アコーディオン選択 |
| 目的地選択 | パンくずリンク | 地域 › 都道府県 › エリアのリンク付きパンくずナビ |
| 交通手段 | 自動判定 | 新幹線（7路線）・飛行機・バスの利用可否を自動判定、料金・所要時間を算出 |
| 交通手段 | 時刻選択 | 時間帯別スロット（新幹線:30分毎/飛行機:1〜2時間毎）。空席○/△残りわずか/✕満席 |
| 交通手段 | 片道/往復 | 往路・復路それぞれ時刻選択（往復は料金×2） |
| ホテル一覧 | 件数 | 各県10〜50件/エリア（人気エリアは50件、地方は10件）。合計2000件以上 |
| ホテル一覧 | フィルター | タイプ・価格スライダー（デュアルレンジ）・星評価・設備12種・エリア。アコーディオン開閉 |
| ホテル一覧 | ソート | 人気順/価格安い順/評価順 |
| ホテル一覧 | ページング | 10件/ページ。ページ番号・前へ/次へボタン。フィルター変更時リセット |
| ホテル一覧 | 広告(PR) | 一部ホテルが広告設定。検索結果ヒット時に先頭に[PR]表示（通常位置にも重複表示） |
| 予約 | 予約フォーム | 大人/子供人数、代表者氏名・メール、お車の有無、特別リクエスト |
| 予約 | 支払い方法 | クレジットカード（申込時決済）または現地払い |
| 予約 | 予約確認 | 全情報まとめて確認してから確定。予約番号発行 |
| 評価 | レビュー投稿 | 宿泊済みホテルに5項目（清潔さ/接客/立地/設備/コスパ）で評価 |
| 評価 | レーダーチャート | Canvas描画のレーダーチャートで評価を可視化 |
| マイページ | 予約履歴 | スケルトンUI付き予約一覧。過去プリセット履歴あり |
| マイページ | レビュー確認 | 投稿済みレビューをレーダーチャートで表示 |
| 認証 | ログイン | 予約にはログインが必要。未ログインはログイン画面へリダイレクト |
| その他 | ローディング | 検索時2〜5秒のローディング表示（リアルな待機演出） |
| その他 | 免責バナー | 全ページ上部に自動化練習サイト旨の黄色バナー |
| その他 | ヘルプ | 操作ガイド・FAQ・新幹線路線一覧・テストアカウント一覧 |

## 技術スタック

- **Vue 3** — Composition API (`<script setup>`)
- **Vue Router 4** — `createWebHashHistory`（GitHub Pages 対応）
- **Vite 5** — ビルドツール
- **JavaScript** — TypeScript なし、外部UIライブラリなし

状態管理はライブラリ不使用（`reactive` ストア + sessionStorage 永続化）。

src/

## 予約フロー

### 宿泊のみ
```
トップ → 目的地選択（地図/リスト） → ホテル一覧 → ホテル詳細 → 予約確認 → 完了
```

### 交通+宿泊セット
```
トップ → 出発地・目的地選択 → 移動手段選択 → ホテル一覧 → ホテル詳細 → 予約確認 → 完了
```
